# 提示词指南

## 基本结构

按「主体 + 动作/状态 + 环境 + 风格 + 光线 + 构图 + 画质」组织，用自然语言陈述句，越具体越好：

> 一只橘猫坐在木质窗台上晒太阳，水彩插画风格，暖色调，午后侧逆光，中景构图，细节丰富

避免堆砌关键词列表；qwen-image 系列自带的 prompt_extend 会自动润色，直白的描述即可。

## 中文文字渲染

qwen-image-3.0 对中英文字渲染最强，技巧：

- 把**要出现的文字原样**写进提示词，并用引号括起：`海报上方写着"春日限定"四个大字`
- 指定字体风格与位置：`黑体标题，居中，红色描边`
- 文字越多、越小，失败率越高；3.0 支持约 10px 小字，但仍建议一条图不超过两三段短文案
- 负面提示词加 `模糊文字, 错别字, 乱码` 可减少出错

## 参数速查

| 参数 | 说明 |
| --- | --- |
| `size` | `宽*高`，如 `1024*1024`、`1536*1024`、`2048*2048`；总像素 512²–2048²，宽高比 1:8–8:1 |
| `n` | 1–6 张 |
| `prompt_extend` | 默认开启，自动改写润色提示词；要精确控制原文时用 `--no-prompt-extend` |
| `negative_prompt` | 排除元素，如 `文字, 水印, 变形` |
| `seed` | 固定随机种子，便于复现与微调 |
| `watermark` | 默认关闭；开启会加"AI 生成"水印 |

## 模型对照

| 模型 | 端点 | 特点 |
| --- | --- | --- |
| `qwen-image-3.0-pro` / `qwen-image-3.0` | 同步 multimodal-generation | 复杂版面、小字、多语言字体最强；单次最多 6 张，2048×2048 |
| `wan2.7-image-pro` / `wan2.7-image` | 异步 image-synthesis | 文生图最高 4096×4096；品牌色调色盘、多图参考、边界框编辑、角色一致性 |
| `z-image-turbo` | 异步 image-synthesis | 快速低成本，写实人像与产品图；仅文生图，1 张/次，2048×2048 |

脚本按模型名前缀自动选择同步或异步通道，无需手动指定。

## 常见风格词（中文可用）

- 画风：水彩、油画、扁平插画、噪点渐变、像素风、3D 渲染、赛博朋克、极简主义
- 摄影：写实摄影、微距、景深、胶片质感、棚拍布光
- 设计：瑞士国际主义、大字报、孟菲斯、毛玻璃、渐变拟物
