# 提示词指南

## 生成

按「主体 + 动作/状态 + 环境 + 风格 + 光线 + 构图」组织，用自然语言陈述句：

> 一只橘猫坐在木质窗台上晒太阳，水彩插画风格，暖色调，午后侧逆光，中景构图

避免堆砌关键词列表；`prompt_extend` 默认开启会自动润色，直白的描述即可。

## 编辑

- 写明保持不变的部分：`保持人物与构图不变，仅把背景换成海边日落`
- 多图时标明角色：`把第一张图的人物画成第二张图的画风`
- 改动越聚焦效果越稳，一次只改一类元素

## 中文文字渲染

- 把要出现的文字原样写进提示词并用引号括起：`海报上方写着"春日限定"四个大字`
- 指定字体风格与位置：`黑体标题，居中，红色描边`
- 文字越多、越小，失败率越高；负面提示词加 `模糊文字, 错别字, 乱码`

## 参数速查

| 参数 | 说明 |
| --- | --- |
| `size` | `宽*高`，总像素 512²–2048²，宽高比 1:8–8:1 |
| `n` | 生成 1–6 张、编辑 1–4 张 |
| `prompt_extend` | 默认开启，自动润色提示词；要精确控制原文时用 `--no-prompt-extend` |
| `negative_prompt` | 排除元素，如 `文字, 水印, 变形` |
| `seed` | 固定随机种子，便于复现与微调 |

## 常见风格词

- 画风：水彩、油画、扁平插画、像素风、3D 渲染、赛博朋克、极简主义
- 摄影：写实摄影、微距、景深、胶片质感、棚拍布光
- 设计：瑞士国际主义、大字报、孟菲斯、毛玻璃
